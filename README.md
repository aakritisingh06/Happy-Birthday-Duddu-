# happy-birthday-duddu

This is a small Vite + React demo for a cute "Happy Birthday duddu" card.

How to run:
1. Ensure Node.js (>=16) is installed.
2. npm install
3. npm run dev
4. Open http://localhost:5173

You can deploy this project to Vercel by linking a GitHub repo and importing the project, or by using Vercel CLI.
